# Enerday – Energy-Based Productivity App

Enerday is a **human-friendly productivity web app** that helps users decide **what to work on right now** based on their **current energy level**, instead of forcing fixed daily schedules or long task lists.

This project is built **without using AI** to strengthen my core frontend skills, product thinking, and real-world problem-solving ability.

---

## 🧠 Product Philosophy

Most productivity apps rely on fixed daily schedules and long to-do lists.  
In real life, free time is unpredictable — traffic delays, health issues, family responsibilities, emergencies, or mental fatigue can disrupt any plan.

Because of this, fixed schedules often:
- Create pressure and guilt when plans fail
- Do not adapt to real-life situations
- Discourage users from continuing after a few bad days

Enerday follows a different philosophy.

Instead of asking users to plan their entire day, Enerday focuses on **real-time productivity**.

The app is designed for the moment when a user thinks:

> “I’m free right now. What should I do?”

At that moment:
- The user selects their **current energy level**
- The app suggests the **best matching task**
- The user chooses **how long they want to work**
- A focus timer starts immediately

This approach:
- Reduces decision fatigue
- Adapts to unpredictable routines
- Avoids guilt-based productivity
- Encourages small, realistic progress

Enerday is not a strict planner.  
It is a **supportive productivity assistant**.

---

## 🔁 How the App Works (Workflow)

(First Time)
→ User signs up
→ User sets general energy preferences (optional)

(Whenever the User Is Free)
→ User opens the app
→ Selects current energy level (High / Medium / Low)
→ App suggests the best task for that energy
→ User sets session duration
→ Task starts with a countdown timer
→ Actual time spent is recorded

(After Work)
→ Task progress is saved
→ User can continue later or complete the task

(Progress)
→ User views task history and simple summaries

## ✨ Main Features

- 🔋 Energy-based task suggestions
- ⚡ “What should I do now?” quick suggest mode
- ⏱️ Focus timer with flexible duration
- 🧠 No fixed daily schedules (stress-free design)
- 📝 Task history with estimated vs actual time
- 📊 Simple progress summaries without guilt
- 🔄 Flexible and realistic task continuation
